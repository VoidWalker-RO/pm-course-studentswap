# Jira Project Setup — StudentSwap

## 1. Загальна інформація про проєкт

- **Назва проєкту:** StudentSwap
- **Тип проєкту:** Scrum
- **Опис:** Маркетплейс для купівлі та продажу вживаних речей серед студентів.
- **Методологія:** Agile / Scrum
- **Оцінювання задач:** Story Points

## 2. Epics

| Epic | Опис |
|---|---|
| Реєстрація та профіль | Реєстрація, авторизація та керування профілем користувача. |
| Управління оголошеннями | Створення, редагування, перегляд і видалення оголошень. |
| Пошук товарів | Пошук товарів за назвою та категоріями, перегляд інформації. |
| Взаємодія з користувачами | Додавання товарів до обраного та зв'язок із продавцями. |

## 3. Sprint 1

- **Тривалість:** 2 тижні.
- **Мета:** Реалізувати базові можливості реєстрації користувачів та створення оголошень.
- **Задачі:** User Stories, відібрані з Backlog відповідно до пріоритетів.
- **Оцінювання:** Story Points.

## 4. Команда

| Роль | Відповідальність |
|---|---|
| Product Owner | Визначення вимог і пріоритетів |
| Scrum Master | Організація роботи та контроль процесу |
| Developer | Реалізація функціональності |

Усі ролі виконує один учасник проєкту.

## 5. Reflection

Під час роботи з Jira було створено Scrum-проєкт StudentSwap, налаштовано дошку, визначено основні епіки та створено User Stories з критеріями приймання й оцінками Story Points. Також було розставлено пріоритети задач відповідно до MoSCoW та запущено перший спринт. Це допомогло краще зрозуміти принципи планування роботи за методологією Scrum і використання Jira для управління проєктом.
